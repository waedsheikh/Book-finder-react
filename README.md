# 📚 Book Finder App

A modern, responsive, and elegant front-end web application built with React.js that allows users to search for books worldwide in real-time using the Open Library API.

---

## ✨ Features

* 🔍 Real-time Book Search: Instantly query thousands of books by their titles using Open Library API.
* 🖼️ Dynamic Cover Display: Automatically fetches and displays book cover images, with fallback placeholders for books lacking covers.
* 📱 Fully Responsive UI: Designed with a sleek, modern Dark Mode aesthetic that looks stunning across all screen sizes (mobile, tablet, desktop).
* ⚡ Fast & Lightweight: Built using Vite and React hooks (useState) for optimal performance and smooth user experience.

---

## 🛠️ Tech Stack & Tools

* React.js (via Vite) – Component-based UI library
* JavaScript (ES6+) – Application logic and asynchronous operations (fetch & async/await)
* CSS3 – Custom responsive layout and dark theme styling
* Open Library API – Public REST API for retrieving literary data
